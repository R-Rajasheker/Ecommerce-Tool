# E-commerce Frontend

This is a React + Vite frontend for the E-commerce Catalog Management Tool.

## Environment
Create a `.env` in `frontend/` (optional) to override the API base URL:

```
VITE_API_URL=http://localhost:5000/api
```

## Setup & Run
```
npm install
npm run dev
```

By default, it calls the backend at `http://localhost:5000/api`.
